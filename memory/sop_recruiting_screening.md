# SOP: Screening applicants and shortlisting

Owner: Talent team. Applies to applicants on HireHub for any open role.

## Screening
- Screen every new applicant for the role against that role's job description (JD) in company memory.
- **Shortlist** an applicant only if they meet ALL must-have criteria in the JD.
- **Reject** an applicant who clearly fails any must-have criterion. Record which criterion failed in the notes.
- If information needed for a must-have criterion is missing from the profile, set stage **Needs Info**
  and note exactly what is missing. Never reject or shortlist on a guess.

## Recording in TalentDesk ATS
- Every screened applicant must exist in TalentDesk with the correct stage and short screening notes.
- Search TalentDesk before creating a candidate. If the candidate already exists, update their stage
  instead of creating a duplicate.

## Scheduling screening calls
- Only Shortlisted candidates can be scheduled. Use a free slot from the TalentDesk interview calendar.
- "Strongest" candidate = meets all must-haves and matches the most nice-to-haves; tie-break on more
  relevant experience, then shorter notice period.
- If the requested slot is not available, book the next free slot on the same day if one exists, otherwise
  the next free slot, and say so in the summary.
